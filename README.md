
# my-school-app

React + Vite 기반의 학교(학생) 서비스 웹앱!

학교 홈페이지를 보다가 별로 학생들에게 필요한 기능이 부족한 것 같아서 고등학생때 뭐가 제일 필요할까 생각해서 간단한 기능을 만들었습니다!

급식 정보, 평균, 표준편차 입력 등급계산기(9등급제, 5등급제 기반, 1~3등급 점수 출력), 선택과목 투표의 기능이 있습니다..

## 기술 스택
-React & Vite
-React Router v7
-jStat(등급 계산용, inverse cdf이용)

## 프로젝트 구조
- `src/` : 컴포넌트
- `vite.config.js` : Vite 설정
